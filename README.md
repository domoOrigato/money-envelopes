# Money Envelopes (phone)

An envelope budget that installs on your phone's home screen and works offline.

- Your numbers stay on your phone. The page is locked so it can't send anything to the internet.
- This repository holds only the empty app. No budget or bank data lives here.
- Add statements as CSV files from RBC or Capital One, or restore a backup from the computer version.

Open the GitHub Pages link in Chrome on Android, then choose **Add to home screen** / **Install app**.
